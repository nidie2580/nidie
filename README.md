# nidie - Yunzai-Bot 插件管理器

一个适用于 [Yunzai-Bot](https://github.com/Le-niao/Yunzai-Bot) 的插件管理器，可在群聊中直接安装、卸载、更新、查看其他插件。

## ✨ 功能特性

- 📦 **一键安装**：通过预设插件名或 git 仓库地址安装插件
- 🗑️ **删除插件**：移除不再需要的插件
- 🔄 **更新插件**：单个更新或一键更新全部 git 插件
- 📋 **插件列表**：以图片形式查看已安装插件
- 📚 **插件市场**：以图片形式查看可一键安装的插件清单
- 🔍 **插件详情**：查看插件版本、git 信息等
- ♻️ **重载插件**：无需重启即可重新加载插件
- 🔒 **权限控制**：危险操作仅主人可用

## 📥 安装

将本插件放入 Yunzai-Bot 的 `plugins` 目录下：

```bash
cd plugins
git clone --depth=1 https://github.com/nidie2580/nidie.git
```

或在 Yunzai 根目录执行（若已安装本插件）：

```
#安装 nidie
```

安装后重启 Yunzai 即可生效。

## 📖 使用说明

发送 `#插件管理帮助` 可查看全部指令。常用指令如下：

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `#安装 <名称\|仓库地址>` | 安装插件 | 主人 |
| `#删除 <名称>` | 删除插件 | 主人 |
| `#更新插件 <名称>` | 更新指定插件 | 主人 |
| `#更新全部插件` | 更新所有 git 插件 | 主人 |
| `#插件列表` | 图片形式查看已安装插件 | 全员 |
| `#插件详情 <名称>` | 查看插件详情 | 全员 |
| `#插件市场` | 图片形式查看可一键安装的插件 | 全员 |
| `#重载插件` | 重新加载所有插件 | 主人 |

### 安装示例

```
#安装 miao-plugin
#安装 https://gitee.com/yoimiya-kokomi/miao-plugin.git
#安装 yoimiya-kokomi/miao-plugin
```

## 📦 可用插件预设

内置了常用 Yunzai 插件的仓库地址，发送 `#插件市场` 可在群内查看，支持一键安装。

## ⚠️ 注意事项

1. 安装/删除/更新操作仅 **主人** 可使用。
2. 插件安装依赖 `git`，请确保服务器已安装。
3. 依赖安装会优先使用 `pnpm`，其次 `npm`。
4. 不会删除插件管理器自身，避免误操作。
5. 安装失败会自动清理残留文件。
6. 列表/市场展示优先用 puppeteer 渲染为图片，无 puppeteer 时降级为文本。
